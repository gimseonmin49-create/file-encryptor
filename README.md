# file-encryptor

파일 입출력으로 문자열을 암호화해 저장하는 C 프로그램입니다. 단계별로 기능을 늘려가며 만들고 있습니다.

## 현재 기능 (1단계)
- 문자열을 입력받아 memo.txt에 저장
- fopen 실패 시 오류 처리 (NULL 검사)

## 진행 계획
- [x] 1단계: 파일에 쓰기
- [ ] 2단계: 파일에서 읽기
- [ ] 3단계: 읽은 내용을 시저 암호로 암호화해 저장
- [ ] 4단계: 복호화
- [ ] 5단계: 메뉴 + 함수 분리
- [ ] 6단계: XOR 암호화로 업그레이드

## 환경
- C, Visual Studio, Windows
